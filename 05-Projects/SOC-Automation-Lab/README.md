# SOC Automation Lab

A detailed documentation of my Security Operations Center (SOC) Automation Lab. This project demonstrates automation workflows using SIEM, EDR, SOAR, and Case Management systems.

## Features

- **Endpoint Monitoring**: Automated endpoint logging using Sysmon.
- **Log Collection & Detection**: SIEM monitoring using Wazuh.
- **SOAR Automation**: Auto-triage and enriching alerts using Shuffle.
- **Incident Response**: Ticket generation and tracking using TheHive.
