# Hands-On Cybersecurity Projects

This directory contains security lab projects, configurations, and simulations I have built to apply cybersecurity concepts in practice.

## List of Projects

*   [**SOC Basic Home Lab**](./SOC-Basic-HomeLab/SOC-Basic-HomeLab.md) - Building a Security Operations Center (SOC) home lab with Splunk, VirtualBox, and Metasploit, simulating attacks and analyzing logs.
*   [**SOC Automation Lab**](./SOC-Automation-Lab/README.md) - Deploying an end-to-end automated SOC pipeline using Wazuh (SIEM), Sysmon (Telemetry), Shuffle (SOAR), VirusTotal (Threat Intel), and TheHive (Incident Response).
