# Mohamed Irfan's Cybersecurity Learning Journey

Welcome to my public cybersecurity learning repository. This repo documents my progress through networking, Linux, security tools, TryHackMe rooms, SOC labs, detection engineering, incident response, and SIEM/SOAR workflows.

My current focus is blue-team security: SOC analysis, endpoint and network telemetry, threat hunting, detection logic, and incident response automation.

## Lab Safety

All offensive-security activity documented here is for authorized learning environments only, such as isolated home labs, TryHackMe rooms, intentionally vulnerable targets, and systems I own or have permission to test.
